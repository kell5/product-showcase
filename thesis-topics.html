How To Use

怎么把这个库用出效果

选题不是「挑一个看起来厉害的」，而是「挑一个你手上器材做得完的」。按下面三步走，一般半小时内就能把题目定下来。

01

先按方向筛

16 个方向对应不同的实验室条件和课程要求。先盘点手上有什么主控和模块（STM32、51、ESP32、K210），再回到对应方向里挑，能避免选到「想法很好但板子做不出来」的题目。

02

再用关键词搜

直接搜主控、传感器或功能词，例如「ESP32 门禁」「人脸识别」「PID 温控」「环境监测」，几百条题目里十几秒就能定位到可落地的候选，比逐条翻目录快得多。

03

最后做差异化

在已有题目上换一种传感器、加一个手机端、补一段数据记录与曲线，就是一份能通过开题的改造方案。评审最在意的往往不是题目新不新，而是你有没有把工作量和技术含量说清楚。

How To Choose

怎么挑题目

选题不是选最炫的，而是选能在有限时间内做出完整闭环、答辩讲得清楚的那一个。

1. 先定主控，再定场景

51 单片机适合入门与纯硬件方向；STM32 适合传感器多、需要实时控制的题目；ESP32 适合联网、App 远程控制；配 Java/Python 后台则偏管理信息系统。

2. 保证一条完整闭环

采集 → 显示 → 阈值判断 → 执行/报警 → 远程查看，闭环齐全的题目更容易写出章节结构，也更好演示。

3. 亮点控制在 3 个以内

功能堆太多容易做不完。挑 3 个核心亮点做扎实，剩下的写进「后续可拓展」，答辩时反而是加分项。

4. 同方向可替换主控

同一场景内的题目可以自由替换主控（STM32 / 51 / ESP32 / GD32），技术栈只需同步替换主控与开发环境即可。

没找到合适题目？

可以按你的专业方向、已有硬件和时间安排，帮你把题目缩小到能落地的范围，或在现有题目上做差异化改造。
