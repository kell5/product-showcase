## 五、接到本站的最短路径

`api.php` 已经是一个单文件后端，加一个 action 就是完整链路：

```php
// api.php 里新增（示意）
case 'ai_ask':
    // 1. 只允许同源请求 + 每 IP 限流（复用 add_message 的限流函数）
    // 2. API Key 只放服务端：data/ai.php（.php 存储，被直接访问时只执行不输出）
    // 3. 转发到 OpenAI 兼容接口
    $payload = [
        'model'    => 'glm-4.7-flash',            // 换厂商只改这一行
        'messages' => [['role' => 'user', 'content' => $q]],
    ];
```

要点：

- 三家都提供 **OpenAI 兼容的 base_url**，换厂商只需改 `base_url` + `model` 两处，
  把这两个值写进配置，不要散落在代码里。
- API Key **绝不能进前端**。前端只调本站 `api.php`，由服务端带 Key 出去。
- 打开控制台的「免费额度用完即停」，否则额度耗尽会自动转按量扣费。
- 给每个 IP 设日调用上限；公开站点被刷是最常见的烧钱方式。

## 六、站内可以做什么（按性价比排序）

1. **选题助手**：用户输入「我手上只有 51 单片机 + DHT11」，先本地检索 699 条库里
   相关的 10 条（纯 JS 就能做，零成本），再让模型用一句话解释怎么改造成差异化方案。
   检索在前、模型在后，token 消耗极低。
2. **留言自动分类**：判断是「问选题 / 求代码 / 广告」，广告直接进待审，不直接公开。
3. **项目页摘要**：把长页内容压成 3 条要点，模型生成一次后缓存成静态文本。
